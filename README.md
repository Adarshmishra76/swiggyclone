# 🍔 Swiggy Clone

A responsive Swiggy-inspired food ordering web application built using **React**, **Parcel**, **Tailwind CSS**, and **Redux Toolkit**.

## 🚀 Features

- 🍕 Browse restaurants
- 📖 Restaurant menu page
- 🔍 Search food items
- 🛒 Shopping cart using Redux Toolkit
- 🍽️ Food, Grocery & Dine sections
- 🏙️ Cities with food delivery section
- 📱 Download App section
- 🔐 Sign In page
- 📄 Responsive footer
- ⚡ Fast performance with Parcel Bundler

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/Adarshmishra76/swiggyclone.git
```

Move into the project

```bash
cd swiggyclone
```

Install dependencies

```bash
npm install
```

---

## ▶️ Run the Project

Start the development server

```bash
npx parcel src/index.html
```

Open your browser

```
http://localhost:1234
```

---

## 🏗️ Build for Production

```bash
npx parcel build src/index.html
```

The production build will be generated inside the `dist` folder.
